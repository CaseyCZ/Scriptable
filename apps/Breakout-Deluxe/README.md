# 🧱 Breakout Deluxe

Offline arkádová hra pro iPhone/iPad v aplikaci **Scriptable**.

## Funkce

- Pálka ovládaná dotykem a barevné cihly.
- Skóre, rekord, 3 životy a postupně rychlejší úrovně.
- Obtížnost: lehká, normální, těžká.
- Motivy: Vesmír, Oceán, Neon.
- Zvuky, pauza, nová hra; vše funguje offline.
- Automatická kontrola aktualizací při spuštění (offline se přeskočí), před instalací nové verze se vytvoří záloha původního skriptu.

## Instalace

Otevři soubor [Breakout Deluxe.scriptable](./Breakout%20Deluxe.scriptable) v aplikaci Scriptable, nebo zkopíruj [Breakout Deluxe.js](./Breakout%20Deluxe.js) do složky Scriptable na iCloud Drive.

## Ovládání

- Táhnutím prstu po hřišti posouváš pálku.
- Klepnutím nebo tlačítkem **Spustit hru** odpálíš míček.
- Tlačítkem **Pauza** lze hru zastavit.

Verze **1.1.0**. Vlastní implementace inspirovaná klasickým Breakoutem a [CodeGuppy](https://codeguppy.com/games/).
