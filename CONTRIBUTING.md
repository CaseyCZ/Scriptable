# Contributing / Přispívání

Díky za zájem o projekt. Issues a pull requesty jsou vítané v češtině i angličtině.

## Hlášení chyb

Použij prosím šablonu **Bug report** a uveď aplikaci, verzi, iOS a verzi Scriptable, přesný postup a co se skutečně stalo.

**Nikdy nevkládej do Issue API klíče, tokeny, osobní data ani jiné tajné údaje.**

## Návrhy funkcí

Použij šablonu **Feature request**. Popiš problém, který chceš vyřešit, a navrhované chování.

## Pull requesty

- změny drž co nejmenší a zaměřené na jeden problém;
- zachovej stávající funkce, pokud není odstranění výslovně cílem změny;
- `apps/LockScreenGenerator/LockScreenGenerator.js` zůstává jako jeden distribuční JavaScript soubor;
- nevkládej API klíče, tokeny ani lokální uživatelská nastavení;
- pokud přidáváš komunitní aplikaci do webového katalogu, zachovej původního autora, odkaz na původní repozitář a stahování z původního zdroje — cizí skripty do repozitáře nekopíruj;
- před odesláním ověř, že upravený JavaScript nemá syntaktickou chybu a že webové odkazy fungují.

## Struktura našich aplikací

Každá vlastní aplikace patří do samostatné složky pod `apps/` a měla by mít alespoň vlastní `README.md`.

---

Contributions are welcome in Czech or English. Please keep changes focused, do not include secrets, and preserve original attribution for third-party projects listed in the community catalog.
