# 🧱 Breakout Deluxe

Offline brick-breaker arcade game for **Scriptable** on iPhone/iPad.

## Features

- Touch-controlled paddle and colorful bricks.
- Score, best score, three lives, and increasingly fast levels.
- Easy / Normal / Hard difficulty.
- Space / Ocean / Neon themes.
- Optional sound effects, pause, restart, fully offline play.
- Startup version check and confirmed update, with a backup of the previous script. Offline launch still works.

Settings displays the version and a **Check for updates** button. Automatic checks run on launch and offer to install new versions.\n\n## Installation

Open [Breakout Deluxe.scriptable](./Breakout%20Deluxe.scriptable) with Scriptable, or copy [Breakout Deluxe.js](./Breakout%20Deluxe.js) to the iCloud Drive Scriptable directory.

Drag on the board to move the paddle; tap or press **Start** to launch the ball.

Version **1.2.0**. Original implementation inspired by classic Breakout and [CodeGuppy](https://codeguppy.com/games/).
