# 🔴 Sports Live

Připravená složka pro druhou sportovní aplikaci **Sports Live**.

Sports Live bude zaměřený na rychlý živý přehled napříč sporty, zatímco **Sports Info** je detailní widget pro vybraný sport / soutěž / tým.

Plánované sporty: ⚽ fotbal, 🏒 hokej, 🏀 basketbal, 🥅 florbal a ⚾ baseball.

Použijeme stejný CaseyCZ template: náhledy, moderní nastavení, API/zdroje, diagnostika, cache/fail-open, údržba, import/export a aktualizace.
